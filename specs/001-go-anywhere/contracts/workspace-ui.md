# 工作區 UI 契約

## 預設語言與導航

所有使用者可見文字預設為繁體中文。行動版底部主要導航固定提供：`探索`、`行程`、`新增`、`預訂`、`我的`。

旅程工作區提供四個同層級檢視：`時間軸`、`地圖`、`預訂`、`筆記`。時間軸與地圖是同等主要檢視，不得把地圖降級成僅在桌面顯示的次要功能。

## 工作區 URL 狀態

建議使用下列可分享但不含私人內容的路由狀態：

```text
/trips/{tripId}?view=timeline&date=YYYY-MM-DD&item={itineraryItemId}
```

- `tripId`：目前旅程。
- `view`：`timeline`、`map`、`bookings`、`notes`。
- `date`：目前日期；未指定時使用旅程開始日或產品定義的當日規則。
- `item`：可選選取項目；項目不存在或不屬於旅程時清除，不暴露資料。
- 切換 `timeline` 與 `map` 不得移除或重設 `date`。

## 時間軸契約

- 依目前日期顯示行程項目。
- 卡片優先顯示時間、標題、類型、地點與重要預訂狀態。
- 長地址、長筆記與次要 metadata 只在詳情顯示。
- 未填時間的項目仍顯示於日期群組，並以繁體中文標示待補時間。
- 日期無項目時顯示每日空狀態與新增入口。
- 選取卡片開啟與地圖 marker 相同的詳情體驗。

## 地圖契約

- 只顯示目前 `date` 且其關聯 Place 的 latitude/longitude 通過範圍驗證的行程項目；座標是由 Place 衍生，不直接寫入行程項目。
- marker 至少攜帶 itinerary item ID、顯示標題、時間與順序資訊。
- 選取 marker 顯示簡短預覽，並能開啟同一個詳情路由/元件。
- 無座標項目不得被當作錯誤刪除，仍須在時間軸、預訂與詳情可用。
- Mapbox 失敗顯示地圖不可用狀態與回到時間軸的操作；不得遮蔽旅程資料。

## 新增流程契約

新增流程第一步只顯示六種類型選擇：`航班`、`住宿`、`交通`、`景點`、`餐廳`、`其他`。
選擇類型後才顯示對應欄位；不得顯示包含所有類型欄位的單一巨大表單。表單儲存失敗時保留輸入並提供重試。

## 詳情契約

詳情視圖依序突出：標題、日期、時間、地點；次要區塊顯示完整地址、預訂資料、筆記與類型專屬資訊。必須提供 `編輯` 與 `刪除`，刪除使用明確確認對話框。

## 預訂與筆記契約

- 預訂是由現有行程項目及其 Booking 關聯產生的篩選/重組視圖，每筆可返回原行程詳情。
- 沒有預訂時顯示空狀態，不建立獨立副本。
- 筆記是旅程層級文字內容，可查看、編輯、儲存；儲存失敗保留草稿。

## 必備產品狀態

每個主要資料載入與 mutation 流程必須可呈現：載入中、空內容、成功、可恢復儲存失敗、網路/離線失敗、地圖不可用、刪除確認與取消。狀態文字和操作均使用繁體中文。
